# 🔐 Python Kayıt ve Giriş Sistemi

Python kullanılarak geliştirilmiş, temel kullanıcı kayıt ve giriş işlemlerini gerçekleştiren bir konsol uygulamasıdır.

## 📌 Özellikler

- **Kullanıcı Kaydı:** Kullanıcı adı ve şifre ile kayıt oluşturma.
- **Şifre Doğrulama:** Kayıt sırasında girilen iki şifrenin eşleşip eşleşmediğini kontrol etme.
- **Kullanıcı Girişi:** Kayıtlı kullanıcı adı ve şifre bilgileriyle giriş yapma.
- **Giriş Denemesi Sınırı:** Hatalı girişlerde deneme sayısını takip etme.
- **Hesap Kilitleme:** 5 başarısız giriş denemesinden sonra hesabı kilitleme.
- **Çıkış İşlemi:** Kullanıcının istediği zaman sistemden çıkabilmesi.
- **İşlem Kontrolü:** Geçersiz komutları kontrol ederek kullanıcıyı bilgilendirme.

## 🛠️ Kullanılan Teknolojiler

- Python 3
- While Döngüleri
- If / Elif / Else Koşulları
- Boolean Değişkenler
- Input / Print Fonksiyonları
- Karşılaştırma Operatörleri
- Break Komutu

## 🎯 Projenin Amacı

Bu proje, Python programlama dilinde öğrendiğim temel konuları uygulamaya dökmek amacıyla geliştirilmiştir.

Özellikle döngüler, koşullu ifadeler, değişken yönetimi ve kullanıcı etkileşimi konularında pratik yapmayı hedeflemektedir.

## ⚠️ Not

Bu proje eğitim amaçlıdır. Kullanıcı bilgileri bellekte geçici olarak tutulur. Veritabanı veya güvenli şifre saklama sistemi kullanılmamaktadır.



# 🔐 Python Registration and Login System

A console-based application developed with Python that performs basic user registration and login operations.

## 📌 Features

- **User Registration:** Create an account using a username and password.
- **Password Verification:** Check whether the password and password confirmation match.
- **User Login:** Log in using registered username and password credentials.
- **Login Attempt Limit:** Track the number of failed login attempts.
- **Account Lockout:** Lock the account after 5 consecutive failed login attempts.
- **Exit Function:** Allow users to exit the system whenever they want.
- **Input Validation:** Detect invalid commands and inform the user.

## 🛠️ Technologies Used

- Python 3
- While Loops
- If / Elif / Else Statements
- Boolean Variables
- Input / Print Functions
- Comparison Operators
- Break Statement

## 🎯 Project Purpose

This project was developed to put the fundamental concepts of Python programming into practice.

The main goal is to improve my understanding of loops, conditional statements, variable management, and user interaction.

## ⚠️ Note

This project is intended for educational purposes. User information is stored temporarily in memory. No database or secure password storage system is implemented.
